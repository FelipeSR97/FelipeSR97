# Olá, eu sou o Felipe 👋🌱

**Engenheiro Agrônomo | Agricultura de Precisão | Dados e Automação no Agro**

Trabalho na ponte entre o **campo** e a **tecnologia**. Sou Consultor de Soluções Conectadas em uma concessionária John Deere em Uberlândia-MG, onde ajudo produtores e equipes a tirar mais valor das máquinas conectadas, dos dados de operação e das ferramentas de agricultura digital.

Com formação em Agronomia (UFU) e Eletrônica (SENAI), uso programação e análise de dados para resolver problemas reais do dia a dia no agro.
